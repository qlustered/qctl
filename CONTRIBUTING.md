# Contributing

Thank you for your interest in qctl.

This repository is a release mirror: qctl is developed in a private
repository, and each release is published here as a single commit. For that
reason **pull requests are not accepted**; a change merged here would be
overwritten by the next release.

**Issues are welcome.** Open one for a bug, a confusing message or a missing
feature. A useful bug report includes:

- the output of `qctl version`
- the command you ran and what it printed, with `-v` for more detail
  (remove tokens, emails and data first)
- what you expected instead

Report security vulnerabilities privately, as described in
[SECURITY.md](SECURITY.md), not in an issue.
